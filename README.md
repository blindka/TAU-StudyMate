# TAU StudyMate - תקשורת ולימודי עבודה (אוניברסיטת תל אביב)

אפליקציית אנדרואיד מודרנית ב-**Kotlin** וב-**Jetpack Compose Material 3** שפותחה במיוחד עבור סטודנטים בתואר דו-חוגי (תקשורת ולימודי עבודה באוניברסיטת תל אביב).

---

## 🌟 תכונות מרכזיות (Features)

1. **הפרדה חוגית ברורה:**
   - 🔵 **תקשורת** (Communication)
   - 🟢 **לימודי עבודה** (Labor Studies)
   - 🟣 **כללי / בחירה**
   - מעקב אחר חלוקת הזמן בין שני החוגים בתואר.

2. **ניהול קורסים מודולרי (Course Hub):**
   - קורסים מנוהלים לפי **מספר קורס** (פורמט TAU כגון `1082.1100`, `1051.1100`).
   - לכל קורס יש 3 תיקיות ייעודיות:
     - 📄 **סיכומים וחומרי לימוד**
     - 🎥 **הקלטות וקישורי צפייה (Panopto / Zoom)**
     - 📝 **מטלות משויכות לקורס**

3. **לשונית מטלות מתקדמת:**
   - סימון מהיר של "בוצע / לא בוצע".
   - מחיקה מהירה ב-**Swipe**.
   - סינונים לפי חוג (תקשורת / לימודי עבודה) ולפי סטטוס.
   - **ייצוא ושיתוף:** ייצוא הדוח המלא לוואטסאפ, למייל או העתקה ללוח בלחיצת כפתור אחת.

4. **מערכת תגמול וגיימיפיקציה (Celebration Rewards):**
   - עם סיום מטלה קופץ חלון תגמול מעוצב עם **אנימציית קונפטי**, מונה רצף ימי למידה (Streak) והודעות מוטיבציה מרימות.

5. **תזכורות: "מה חסר לי ללמוד?":**
   - סעיף מובלט במסך הבית המתריע על חומרים חסרים, סיכומים להשלמה או הקלטות שטרם נצפו.

6. **פיתוח הרגלי למידה ואנליטיקה אדפטיבית:**
   - **טיימר פוקוס אינטראקטיבי** המקושר לקורס או למטלה.
   - השוואה בין זמן ביצוע משוער (Estimated Time) לזמן בפועל (Actual Time).
   - תובנות למידה חכמות המבוססות על קצב הלמידה האישי.

---

## 🛠️ ארכיטקטורה וטכנולוגיות

- **שפה:** Kotlin 2.0
- **ממשק משתמש:** Jetpack Compose (Material 3) עם תמיכה מלאה ב-RTL ועברית
- **בסיס נתונים מקומי:** Room Database (Offline-first)
- **ארכיטקטורה:** MVVM עם StateFlow ו-Coroutines
- **אנימציות:** Canvas Particle Engine (קונפטי לחגיגת סיום מטלות)
